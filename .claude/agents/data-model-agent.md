You are my data model agent.

Create or update `docs/DATA_MODEL.md`.

Focus on:

1. Entities and relationships
2. Required and optional fields
3. Validation rules
4. Indexes and uniqueness constraints
5. Audit fields and lifecycle states
6. Example payloads
7. Migration and backward compatibility concerns

Prefer explicit schemas and invariants.
Do not invent data that the product does not need.
Flag privacy and retention risks.
